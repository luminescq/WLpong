## О проекте

**WLpong** — это современное приложение с выдающимся дизайном для мониторинга сетевых задержек (ping), доступности хостов и состояния сервисов.
Под капотом используется связка **Flutter** (для плавного пользовательского интерфейса с частотой 60-120 fps) и **Rust** (для высокопроизводительного, многопоточного и точного сетевого движка).

---

## Ключевые возможности

- **Производительное ядро на Rust**: Параллельная проверка множества доменов без просадок кадров в UI.
- **Выдающийся дизайн**: Премиальный пользовательский интерфейс с матовым стеклом (Frosted Glass), плавными анимациями и настраиваемой производительностью.
- **Детальная статистика**: Отслеживайте число проверок и успешность прямо на дашборде.
- **Privacy First**: Ваша история и статистика хранятся исключительно локально на вашем устройстве. Вы можете очистить её в любой момент.
- **Полный контроль**:
  - Настройка пользовательских DNS-серверов.
  - Управление таймаутами.
  - Гибкие профили доменов для мониторинга.
- **Performance Mode**: Умный режим для слабых телефонов, отключающий ресурсоемкие шейдеры и анимации без потери общей эстетики.
